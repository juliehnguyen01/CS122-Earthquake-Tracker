**Project Description:**

For this project assignment, we have decided to create a Global Earthquake Tracker and Analyzer developed using Python. Moreover, this program will enable users to explore earthquake activity around the world. Users will have the ability to select different locations, specific date ranges, and earthquake magnitudes to retrieve information from the internet. The program will additionally analyze the collected data and showcase earthquake patterns through visualizations such as graphs and statistical calculations. Our end goal is to create a simple yet interactive application to help users better understand earthquake activity worldwide.

**Project Outline / Plan**

1) Interface Plan

- Develop a graphical user interface (GUI) using Python's Tkinter library.
- Add at least 10 interactive features, including buttons, dropdown menus, and text input fields.
- Design at least two separate windows: a home page and an analysis page.
- Allow users to filter earthquake data by region, date, and magnitude.
- Present earthquake statistics and visualizations based on the user's selected filters.

2) Data Collection and Storage Plan (Author #1 - Julie Nguyen)
- Retrieve earthquake data online using the USGS Earthquake API.
- Gather details about earthquakes, including dates, locations, magnitudes, depths, and coordinates.
- Use Python's csv library to organize and save the collected data into CSV files.
- Utilize Python's requests library to access and download earthquake information.
- Save the CSV files locally for future data analysis and visualization.
- Data Source: https://earthquake.usgs.gov/fdsnws/event/1/
